# R0 reliable baseline — 11 September 2026

R0 changes evidence presentation and verification, not the detector's weights, feature order or thresholds. It does not improve or remeasure F1, prove dataset suitability, or certify SIH completion.

## Completed changes

- Same selected station now drives map, sensor trace and evidence panel. No match means unavailable evidence, not a different station's incident.
- Observation age and fetch age are calculated at response time. The dashboard updates age every 30 seconds even without a source refresh. Network age explicitly refers to the newest report only. Missing/future timestamps are not labelled fresh.
- Cached/failed-source status survives completion of a request. Late live responses cannot overwrite a replay view. Synthetic modifications are labelled simulation; rescoring a source copy does not reset its fetch timestamp.
- Removed the synthetic “all sensors healthy” incident, fixed probability floors, feature magnitudes incorrectly presented as model contributions, invented correction intervals and “self-healing applied” claim. Live evidence now retains model outputs without inflation. Local SHAP and safe live corrections are unavailable until implemented and validated. Historical offline outputs remain intact.
- Old cached presentation records are suppressed on loading. Old source rows remain available with unverified simulation provenance until a fresh fetch. No original cache file is deleted by migration.
- Verification stops on a native command failure. A regression deliberately exits with code 17 and proves the success message is unreachable. Ordinary verification no longer regenerates historical reports.

## Frozen baseline

- Deployed model: `SkyGuard-P10-compliant`, 108 ordered event features; model policy checked against the historical report.
- Actual live model artifacts: `models/phase10_final.joblib`, `models/phase10_climatology.joblib`. Other model files are retained as non-live historical/candidate artifacts, not silently promoted.
- Manifest: `config/active_model_manifest.json` records feature order, policy, runtime hashes, installed dependency versions, historical evaluation provenance and limitations.
- `reports/r0_baseline/immutable_before.json` and `immutable_after.json` record hashes for 257 model/data files (1,366,412,419 bytes). Live caches and runtime databases are explicitly excluded because they are mutable. Hash receipts are NOT a recoverable backup or a scientific quality check.

## Verification

102 Python tests passed, including new age, evidence and failure-propagation checks. Both JavaScript regression programs passed, including asynchronous source failure and station-isolation checks. Four dashboard JavaScript files passed syntax checks. All 257 protected files were byte-identical after verification. One existing Starlette/httpx deprecation warning remains. No browser visual/interaction QA or new labelled accuracy evaluation was performed.

Use `powershell -NoProfile -ExecutionPolicy Bypass -File verify_skyguard.ps1` from the project folder. `python src/data/run_api.py` remains the canonical startup path.

## Next decision

R1 is a read-first data suitability audit: source measurements and transformations, pressure datum, derived versus measured RH, station coverage/cadence, missing data, synthetic fault labels and actual training lineage. Do not replace the model or download more data until the specific gaps are established. R0 alone does not resolve calibration overlap, in-sample stacking or sparse-neighbour limitations identified previously.
