How this deployed model was developed

Historical development → controlled fault injection → held-out evaluation

Real NOAA/NCEI station observations provide the historical weather context. Temperature and pressure are parsed with source conventions preserved; relative humidity is derived from temperature and dew point. Simulated sensor faults supply known evaluation labels; these are not confirmed real equipment failures.

The deployed Phase 10 detector uses 108 features from temperature, pressure and humidity, including temporal change and neighbouring-station evidence. LightGBM-gated decisions use known/new-station policies. The causal TCN remains advisory because its fusion exceeded the unseen-station false-alarm limit.

Tests below separate unseen time and unseen stations in 2024. Precision measures how many flags are correct; recall measures how many faults are found; F1 balances them. Episode recall measures whether an incident was detected at least once—not whether every faulty row was detected. These are historical injected-fault results, not live accuracy.

This approach is suitable for a computer-only SIH demonstration because it combines genuine observations, reproducible fault labels, causal processing and measurable false alarms. It is not proven to be the best method. Missed weak faults, source differences and limited real fault labels remain limitations. Later experimental notebooks are not automatically the deployed model.
