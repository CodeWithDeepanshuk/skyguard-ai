Core Technologies & Purpose
❖
Next.js 14 & React 18 (Operator UI): Fast, responsive web dashboard so station operators can monitor alerts and sensor health without delay.
❖
MapLibre GL (Station Map): Visualizes weather stations across the region on an interactive map with green, red, and amber health dots.
❖
Recharts (Live Weather Graphs): Draws smooth 24-hour diurnal curves for temperature, pressure, and humidity to easily spot sudden shifts.
❖
Python 3.12 & FastAPI (Core Backend): High-speed server that streams incoming station telemetry and executes AI quality tests in under a second.
❖
PostgreSQL (Central Database): Scalable relational database using psycopg that stores historical weather data and audited alert records.
❖
SQLite (Offline / Local Cache): Stores data locally so demonstrations and field stations function seamlessly without active internet.
❖
LightGBM & Scikit-learn (AI Models): Trained machine learning models (Gradient Boosting & Isolation Forest) to spot complex, multi-sensor anomalies.
❖
CUSUM Algorithm (Drift Detector): Cumulative sum tracking that catches aging sensors that slowly drift out of calibration over days.
❖
Physical Limit & Step QC (Rule Checks): Immediate WMO rules that reject impossible readings (e.g., 75°C) and sudden 10°C spikes in one minute.
❖
Spatial Consensus (Peer Validation): Compares readings with neighboring stations (accounting for altitude & distance) to verify local trends.
❖
Decision & Triage Logic (Classifier): Separates real extreme weather from broken sensor hardware, stopping false alarms before dispatch.
❖
Physics-Based Imputation (Gap Filling): Generates clean replacement estimates for faulty values so downstream weather forecasting models don't crash.
❖
Raw Data Integrity (Audit Trail): Original sensor measurements are never erased or modified; quality flags are attached transparently.
